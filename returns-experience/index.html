Designing a Scalable Returns Portal Experience

A mobile-first, modular UX solution for parcelLab’s white-label platform

At parcelLab, I designed the company’s first Returns Portal Template — a white-label solution for brands like H&M to offer customers an easy way to return or exchange products online. The goal was to create a clear, mobile-friendly experience that could be customized for different brands and return policies.

Pain Points

  • Needing to contact customer service to initiate returns
  • Having to print return labels or drop off packages manually
  • Uncertainty around policies or exchange availability
  • No visibility into refund status or timeline
  • Limited or confusing options for product exchanges

Desktop Experience

Although designed mobile-first, I created a responsive desktop experience tailored for users returning items from home, where form entry, label printing, and multitasking are more natural. The example below demonstrates the full desktop flow.

Starting the Flow

Users enter their order number and email to initiate a return.

Select Return Reason

Simplifies decision-making by grouping return reasons into logical, user-friendly blocks, reducing cognitive friction.

Select a Return Method

Visually distinguishes courier and postal options with clear layout, icons, and benefits — supporting fast decision-making.

Choose a Pickup Date

Calendar interface allows quicker visual scanning and fewer input errors for time selection.

Confirmation + QR Code & Label

Final screen offers reassurance and multiple follow-up options — download label or use QR in-store, catering to user preferences.

Outcome / Learnings

  • Helped launch the first return solution at parcelLab
  • Adopted by multiple clients, starting with H&M
  • Reduced support tickets by 75%
  • Learned how to design for scale, clarity, and reuse

Impact

  • 75% drop in customer service inquiries
  • 5% fewer return requests due to improved UX clarity

My Role & Process

I mapped the return flow, designed all screens for mobile and desktop, and created a modular, brand-neutral design system in Figma. I worked closely with product and engineering to ensure logic and flexibility.
